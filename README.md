# vetKlinika

Веб-приложение для учёта клиентов и питомцев ветеринарной клиники. Backend на Go с REST API и SQLite, простой фронтенд на HTML, CSS и JavaScript.

> Статус: в разработке. Основные операции с клиентами, питомцами и типами животных работают, остальное в планах (см. ниже).

## Возможности

- Клиенты (владельцы): создание, просмотр списка, поиск по имени и по id, редактирование, удаление.
- Питомцы: создание, просмотр, поиск по владельцу, редактирование, удаление. Поля: кличка, вес, возраст, тип животного, анамнез.
- Справочник типов животных: просмотр, поиск, добавление.
- Страницы: список клиентов, создание клиента, карточка клиента, карточка питомца.

## Стек

- Go (стандартная библиотека `net/http`)
- SQLite через `modernc.org/sqlite` (без CGO)
- `cleanenv` для конфигурации из YAML
- HTML, CSS и JavaScript без фреймворков

## Структура

```text
backend/
  cmd/main.go            точка входа
  internal/handlers/     HTTP-обработчики (persons, pets, types)
  internal/middleware/   прокидывание хранилища в контекст запроса
  internal/server/       маршруты и запуск сервера
  internal/service/      загрузка конфигурации
  internal/storage/      работа с БД и создание таблиц
frontend/                страницы клиентов и питомцев
config.yaml              настройки (порт, путь к БД)
```

## Запуск

Запускайте из корня репозитория, пути к `config.yaml` и `frontend/` относительные.

```bash
go run ./backend/cmd
```

Откройте в браузере `http://localhost:8080`.

Таблицы создаются автоматически при первом запуске. Настройки лежат в `config.yaml`:

```yaml
db_path: "./db/storage.db"
port: 8080
```

## API

| Метод | Путь | Описание |
|---|---|---|
| GET, POST, PUT, DELETE | `/api/persons` | клиенты (`?id=`, `?name=`) |
| GET, POST, PUT, DELETE | `/api/pets` | питомцы (`?ownerid=`) |
| GET, POST | `/api/types` | типы животных (`?id=`, `?name=`) |
